# time_tracking

Simple Python script for tracking time spent on tasks.
Stores data in simple CSV files and uses DuckDB as CSV processor.

## Installation

1. Make sure you have [the DuckDB Python package](https://pypi.org/project/duckdb/) installed.
2. Copy the file `time_tracking` to any directory that is added in your PATH (e.g. `/bin` on Linux).
3. If you want to have support for bash completions on Linux, copy `time_tracking.bash_completion` to `/etc/bash_completion.d`
